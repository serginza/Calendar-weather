# Calendar-weather

Приложение **"Calendar-weather"** построено на архитектуре FSD и представляет собой календарную сетку с нынешней датой и кнопками перелистывания месяцев.
Дополнительно приложение показывает погоду на сегодняшний день, а так же прогноз на 2 недели (в разработке прогноз на другое кол-во дней и интерфейс фильтра погодных данных). Помимо погоды, в календаре появится список дел (ToDo) со всеми соответствующими сценариями.

Стек: React, TypeScript, zustand, axios, MUI, emotion, SCSS

Локальный запуск: клонировать репозиторий на диск, выполнить установку зависимостей (npm intall или yarn install), запустить проект командой **"npm run dev"**. Сборка запускается на порту **3000** (localhost:3000).
